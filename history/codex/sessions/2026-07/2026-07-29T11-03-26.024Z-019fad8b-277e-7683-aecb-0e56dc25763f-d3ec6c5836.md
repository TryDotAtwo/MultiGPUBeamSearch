## Install
    
    npm install -D @cloudflare/workers-types
    -- Or
    yarn add -D @cloudflare/workers-types

## Usage

The following is a minimal `tsconfig.json` for use alongside this package:

`tsconfig.json`
    
    {
      "compilerOptions": {
        "target": "esnext",
        "module": "esnext",
        "lib": ["esnext"],
        "types": ["@cloudflare/workers-types"]
      }
    }
