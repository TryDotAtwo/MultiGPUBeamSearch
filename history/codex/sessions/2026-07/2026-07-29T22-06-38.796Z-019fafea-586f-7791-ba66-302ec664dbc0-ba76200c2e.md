## Features

  * Compatible with Clash, V2ray/V2fly, Sing-box, Shadowsocks, Sub, Github Subscriptions.

    * Full `clash` config supported, Partial `clash.meta` config supported.
  * A set of routing rules applied to multiple subscription sources automatically selects efficient nodes.

  * Supports custom routing rule groups and node groups.

    * Customizes default routing rule groups for novice users - ready to use right out of the box.
    * Built-in geo-IP, geo-site, ACL, and other rulesets
  * Backup and synchronization, synchronizing multiple devices with a single configuration.

    * Supports iCloud synchronization [IOS/MacOS].
    * Supports synchronization within the local area network.
    * Supports WebDAV.
    * Supports importing/exporting ZIP files.
  * Built-in support for the modified sing-box core.

  * Introduces a beginner mode for simpler configuration.

  * Plan to support more platforms.

Routing for applications in Windows and Android does not work in TUN mode#590

Copy link

## Description

hananijamian

opened on Feb 24, 2025

Issue body actions

Beta versions of Karing VPN starting with stable 527 in TUN mode for Windows and Android cannot identify an application by the process name, path to the process and folder with processes. The application ignores these routing rules and applies general rules for them that are not related to specific applications and processes. The situation changes if you enable the system proxy - then Karing begins to recognize applications and apply the rules correctly. However, the system proxy is only a temporary solution for Windows (at the same time, WhatsApp stops working, which does not like the system proxy), on Android, routing with the application does not work.

L334: ### Fields
L335: 
L336: #### external_controller
L337: 
L338: RESTful web API listening address. Clash API will be disabled if empty.
L339: 
L340: #### external_ui
L341: 
L342: A relative path to the configuration directory or an absolute path to a directory in which you put some static web resource. sing-box will then serve it at `http://{{external-controller}}/ui`.
L343: #### external_ui_download_url
L344: 
L345: ZIP download URL for the external UI, will be used if the specified `external_ui` directory is empty.
L346: 
L347: `https://github.com/MetaCubeX/Yacd-meta/archive/gh-pages.zip` will be used if empty.
L348: 
L349: #### external_ui_download_detour
L350: 
L351: The tag of the outbound to download the external UI.
L352: 
L353: Default outbound will be used if empty.
L354: #### secret
L355: 
L356: Secret for the RESTful API (optional) Authenticate by spedifying HTTP header `Authorization: Bearer [REDACTED] ALWAYS set a secret if RESTful API is listening on 0.0.0.0
L357: 
L358: #### default_mode
L359: 
L360: Default mode in clash, `Rule` will be used if empty.
L361: 
L362: This setting has no direct effect, but can be used in routing and DNS rules via the `clash_mode` rule item.
L363: #### access_control_allow_origin
L364: 
L365: Since sing-box 1.10.0
L366: 
L367: CORS allowed origins, `*` will be used if empty.
L368: 
L369: To access the Clash API on a private network from a public website, you must explicitly specify it in `access_control_allow_origin` instead of using `*`.
L370: 
L371: #### access_control_allow_private_network
L372: 
L373: Since sing-box 1.10.0
L374: 
L375: Allow access from private network.
L376: 
L377: To access the Clash API on a private network from a public website, `access_control_allow_private_network` must be enabled.
L378: #### store_mode
L379: 
L380: Deprecated in sing-box 1.8.0
L381: 
L382: `store_mode` is deprecated in Clash API and enabled by default if `cache_file.enabled`.
L383: 
L384: Store Clash mode in cache file.
L385: 
L386: #### store_selected
L387: 
L388: Deprecated in sing-box 1.8.0
L389: 
L390: `store_selected` is deprecated in Clash API and enabled by default if `cache_file.enabled`.
L391: 
L392: The tag must be set for target outbounds.
L393: 
L394: Store selected outbound for the `Selector` outbound in cache file.
L395: #### store_fakeip
L396: 
L397: Deprecated in sing-box 1.8.0
L398: 
L399: `store_selected` is deprecated in Clash API and migrated to `cache_file.store_fakeip`.
L400: 
L401: Store fakeip in cache file.
L402: 
L403: #### cache_file
L404: 
L405: Deprecated in sing-box 1.8.0
L406: 
L407: `cache_file` is deprecated in Clash API and migrated to `cache_file.enabled` and `cache_file.path`.
L408: 
L409: Cache file path, `cache.db` will be used if empty.
L410: #### cache_id
L411: 
L412: Deprecated in sing-box 1.8.0
L413: 
L414: `cache_id` is deprecated in Clash API and migrated to `cache_file.cache_id`.
L415: 
L416: Identifier in cache file.
L417: 
L418: If not empty, configuration specified data will use a separate store keyed by it.
