# CayleyPy Results Publisher

Public Codex plugin and dependency-free Python CLI for sending validated CayleyPy solutions from Kaggle, clusters, or local machines through the official Cloudflare ingest service into GitHub.

- Human quick start (Russian): [`references/HUMAN_GUIDE_RU.md`](references/HUMAN_GUIDE_RU.md)
- Agent contract: [`references/AGENT_PROTOCOL.md`](references/AGENT_PROTOCOL.md)
- Ready examples: [`templates/`](templates/)
- CLI: [`scripts/cayleypy_submit.py`](scripts/cayleypy_submit.py)

No user token and no endpoint configuration are required.
